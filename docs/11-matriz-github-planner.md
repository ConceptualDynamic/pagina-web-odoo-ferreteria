# Matriz de vínculo GitHub Project ↔ Planner

## Regla base
- GitHub Project: estado macro del trabajo técnico.
- Planner: ejecución diaria por persona.

## Campos espejo
- Estado: Backlog/En curso/Bloqueado/Done ↔ No iniciado/En proceso/Bloqueado/Completado
- Responsable: owner técnico ↔ asignado Planner
- Prioridad: P1/P2/P3 ↔ Urgente/Importante/Media
- Fecha objetivo: due date sincronizada manualmente

## Convención de enlace cruzado
- En cada ítem GitHub: agregar URL de tarea Planner
- En cada tarea Planner: agregar URL de Issue/PR GitHub

## Convención de nombres
- `[Fase X] Título corto` para Issues y tareas
