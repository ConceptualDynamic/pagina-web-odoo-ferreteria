# Guía de implementación: Checkout E2E

Esta guía describe los pasos técnicos para implementar el checkout completo con pagos, envíos e impuestos en Odoo.

## Prerequisitos

- Odoo 16+ instalado y configurado (Fase 1)
- Módulo `website_sale` activado
- Catálogo de productos cargado (Fase 3)
- Diseño de páginas clave implementado (Fase 4)

## 1. Configuración de empresa y contactos

### 1.1 Datos de la ferretería
```
Ajustes → Empresas → Mi empresa
```

```javascript
// static/src/js/checkout_validation.js
odoo.define('ferreteria_checkout.validation', function (require) {
    'use strict';
    
    var publicWidget = require('web.public.widget');
    
    publicWidget.registry.CheckoutValidation = publicWidget.Widget.extend({
        selector: '.oe_website_sale',
        events: {
            'change input[name="partner_vat"]': '_onVatChange',
            'submit #checkout_form': '_onSubmit',
        },
        
        _onVatChange: function (ev) {
            // Validar formato de NIT/cédula
            var vat = $(ev.currentTarget).val();
            if (!this._validateVat(vat)) {
                $(ev.currentTarget).addClass('is-invalid');
            }
        },
        
        _validateVat: function (vat) {
            // Implementar validación según país
            return /^[0-9]{6,10}$/.test(vat);
        },
        
        _onSubmit: function (ev) {
            // Validar formulario completo antes de enviar
            if (!this._validateForm()) {
                ev.preventDefault();
                this._showError('Por favor complete todos los campos requeridos');
            }
        },
    });
});
```

## 7. Lógica de negocio personalizada

### 7.1 Validación de stock en checkout

```python
# models/sale_order.py
from odoo import api, models
from odoo.exceptions import ValidationError

class SaleOrder(models.Model):
    _inherit = 'sale.order'
    
    @api.constrains('order_line')
    def _check_stock_availability(self):
        """Verificar stock antes de confirmar pedido"""
        for line in self.order_line:
            if line.product_id.type == 'product':
                available = line.product_id.qty_available
                if available < line.product_uom_qty:
                    raise ValidationError(
                        f'Stock insuficiente para {line.product_id.name}. '
                        f'Disponible: {available}, Solicitado: {line.product_uom_qty}'
                    )
    
    def action_confirm(self):
        """Confirmar pedido después de pago"""
        self._check_stock_availability()
        return super().action_confirm()
```

### 7.2 Cálculo de descuentos

```python
# models/sale_order.py
from odoo import api, fields, models

class SaleOrder(models.Model):
    _inherit = 'sale.order'
    
    coupon_code = fields.Char(string='Código de cupón')
    discount_amount = fields.Monetary(
        string='Descuento',
        compute='_compute_discount',
        store=True
    )
    
    @api.depends('coupon_code', 'amount_untaxed')
    def _compute_discount(self):
        for order in self:
            if order.coupon_code:
                coupon = self.env['sale.coupon'].search([
                    ('code', '=', order.coupon_code),
                    ('state', '=', 'active')
                ])
                if coupon:
                    order.discount_amount = order.amount_untaxed * (coupon.discount_percent / 100)
                else:
                    order.discount_amount = 0.0
```

### 8.2 Automatizar envío de emails

```python
# models/sale_order.py
from odoo import api, models

class SaleOrder(models.Model):
    _inherit = 'sale.order'
    
    def action_confirm(self):
        """Enviar email al confirmar pedido"""
        res = super().action_confirm()
        template = self.env.ref('ferreteria_checkout.email_template_order_confirmation')
        for order in self:
            template.send_mail(order.id, force_send=True)
        return res
```

## 9. Testing

### 9.1 Tests unitarios

```python
# tests/test_checkout.py
from odoo.tests import tagged, TransactionCase
from odoo.exceptions import ValidationError

@tagged('post_install', '-at_install')
class TestCheckout(TransactionCase):
    
    def setUp(self):
        super().setUp()
        self.product = self.env['product.product'].create({
            'name': 'Martillo',
            'type': 'product',
            'list_price': 50000,
            'qty_available': 10,
        })
        self.partner = self.env['partner'].create({
            'name': 'Cliente Test',
            'email': 'test@example.com',
        })
    
    def test_order_creation(self):
        """Test creación de pedido"""
        order = self.env['sale.order'].create({
            'partner_id': self.partner.id,
        })
        self.env['sale.order.line'].create({
            'order_id': order.id,
            'product_id': self.product.id,
            'product_uom_qty': 2,
        })
        
        self.assertEqual(order.amount_total, 119000)  # 2 * 50000 * 1.19 (IVA)
    
    def test_insufficient_stock(self):
        """Test validación de stock insuficiente"""
        order = self.env['sale.order'].create({
            'partner_id': self.partner.id,
        })
        self.env['sale.order.line'].create({
            'order_id': order.id,
            'product_id': self.product.id,
            'product_uom_qty': 20,  # Más que el stock disponible
        })
        
        with self.assertRaises(ValidationError):
            order.action_confirm()
```

## 11. Troubleshooting común

### 11.1 "Payment failed"
**Causa**: Credenciales incorrectas de proveedor de pago
**Solución**: Verificar API keys en modo producción

### 11.2 "Shipping method not available"
**Causa**: Dirección fuera de zona de cobertura
**Solución**: Configurar método de envío con cobertura nacional o mensaje claro

### 11.3 "Tax calculation error"
**Causa**: Impuestos no asignados a productos
**Solución**: Asignar IVA 19% a todos los productos

### 11.4 "Order stuck in draft"
**Causa**: Webhook de pago no recibido
**Solución**: Verificar URL de webhook y logs del proveedor
