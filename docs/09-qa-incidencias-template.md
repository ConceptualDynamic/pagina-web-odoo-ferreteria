## Estados de Incidencias

- **Nuevo**: Incidencia recién detectada, sin revisar
- **Confirmado**: Incidencia reproducida y validada
- **En Progreso**: Equipo de desarrollo trabajando en fix
- **Pendiente Re-test**: Fix implementado, esperando validación QA
- **Re-test Fallido**: Fix no resuelve el problema, vuelve a desarrollo
- **Resuelto**: Fix validado por QA, funciona correctamente
- **Cerrado**: Incidencia completamente cerrada
- **Postergado**: Incidencia conocida pero se decide postergar para post-launch
- **No será corregido**: Incidencia validada pero se decide no corregir
