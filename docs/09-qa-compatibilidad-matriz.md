## Checklist de Características Móviles

### Interacciones Táctiles
- [ ] Tap funciona en todos los botones
- [ ] Swipe funciona en carousels/sliders
- [ ] Pinch zoom funciona en imágenes (donde aplique)
- [ ] Scroll suave y natural
- [ ] Botones tienen tamaño mínimo 44x44px
- [ ] Espaciado adecuado entre elementos interactivos

### Formularios Móviles
- [ ] Teclado apropiado para cada tipo de input
  - [ ] Email: teclado con @
  - [ ] Teléfono: teclado numérico
  - [ ] Número: teclado numérico
  - [ ] URL: teclado con .com
- [ ] Campos de input tienen tamaño adecuado
- [ ] Labels visibles y claros
- [ ] Validación en tiempo real funciona
- [ ] Mensajes de error visibles
- [ ] Botón de envío siempre accesible

### Navegación Móvil
- [ ] Menú hamburguesa funciona suavemente
- [ ] Navegación con breadcrumbs visible
- [ ] Botón "atrás" funciona correctamente
- [ ] Links no muy cerca entre sí
- [ ] Footer accesible

### Carrito y Checkout Móvil
- [ ] Icono de carrito siempre visible
- [ ] Contador de items visible
- [ ] Proceso de checkout claro
- [ ] Campos de pago accesibles
- [ ] Botones grandes y claros
- [ ] Resumen de orden visible

### Performance Móvil
- [ ] Página carga en < 5 segundos en 3G
- [ ] Imágenes optimizadas para móvil
- [ ] No scroll horizontal involuntario
- [ ] Animaciones suaves (60fps)

### Orientación
- [ ] Portrait mode funciona perfectamente
- [ ] Landscape mode funciona perfectamente
- [ ] Transición entre orientaciones suave
- [ ] Layout se adapta correctamente
